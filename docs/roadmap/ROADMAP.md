# Roadmap

| Milestone | Focus | Exit Criteria |
|---|---|---|
| M0 | Foundation | Modules, contracts, CI and standards |
| M1 | Project Core | Create/open/save/autosave/versioning |
| M2 | Drawing | Canvas, brush, layers, onion skin |
| M3 | Animation | Timeline, keyframes, playback |
| M4 | Scenes | Shots, cameras, scene organization |
| M5 | Characters | Rigging, poses, reusable assets |
| M6 | Audio | Tracks, markers, synchronization |
| M7 | Compositing | Masks, blend modes, effects |
| M8 | Export | Offline render queue and video output |
| M9 | Performance | Profiling, memory and GPU optimization |
| M10 | Production | Stability, recovery and compatibility |
| M11 | Extensions | Import/export and plugin contracts |
| M12 | Intelligent Tools | Optional AI-assisted workflows |

## Definition of Done

A feature is complete only when behavior is tested, persistence is versioned, undo/redo is defined, performance is measured, failure recovery is considered, accessibility is reviewed, and documentation exists.
