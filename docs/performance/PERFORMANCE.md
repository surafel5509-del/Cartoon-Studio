# Performance Engineering

Performance is measured with representative projects.

## Benchmarks

- Startup time
- Project open/save time
- Canvas input latency
- Timeline scrub latency
- Frame evaluation time
- Preview render time
- Memory peak
- Texture memory
- Autosave duration
- Export throughput

## Strategies

Use profiling-driven caching, dirty-region rendering, thumbnail caching, bounded memory caches, background work and progressive preview quality. Avoid optimization without evidence.
