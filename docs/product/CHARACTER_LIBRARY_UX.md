# Character Library UX

## Browser

The Character Library shows:

- character thumbnail;
- name;
- style/category;
- favorite state;
- number of available animation clips;
- rig availability;
- search and filter controls.

## Character Detail

After selecting a character:

**Large Preview**

Below it:

**Animation Strip / Clip Browser**

Example:

[Idle] [Walk] [Run] [Jump] [Fall] [Wave] [Talk] [Laugh] [Cry] [Dance] ...

Selecting a clip previews it immediately.

## Scene Integration

Actions:
- Add to Scene
- Add with Animation
- Add as New Instance
- Customize
- Open Character Studio

## Character Studio

The same character can be edited at a deeper level:

Artwork -> Rig -> Poses -> Expressions -> Animation -> Preview -> Save Variant
