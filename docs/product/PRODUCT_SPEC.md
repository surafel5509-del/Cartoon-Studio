# Product Specification

## Workflow

1. Create project
2. Configure resolution and frame rate
3. Create scenes and shots
4. Build characters and assets
5. Draw or import artwork
6. Animate on timeline
7. Add camera movement
8. Add audio and synchronization markers
9. Composite layers and effects
10. Preview
11. Render
12. Export and archive

## Workspaces

Home, Storyboard, Drawing, Animation Timeline, Scene/Camera, Character Rigging, Asset Library, Audio, Compositing, Export Queue and Project Settings.

## UX Principles

Fast tool access, gesture-friendly canvas, contextual panels, customizable workspace, clear hierarchy, accessibility, non-destructive editing, autosave and recovery.
