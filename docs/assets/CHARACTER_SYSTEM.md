# Character System

Characters are structured production assets, not flat images.

## Character Package

A character may contain:

- identity metadata;
- multiple visual styles;
- body parts/layers;
- vector or raster artwork;
- rig;
- bones and constraints;
- facial controls;
- expressions;
- poses;
- animation clips;
- materials/colors;
- thumbnails;
- preview scenes;
- optional voice/audio references.

## Character Library

The initial product target is a library of **30+ professionally authored character packages**, each with a coherent set of reusable animations.

The architecture must not hard-code 30 characters. Characters are data-driven so the library can grow to hundreds or thousands of assets.

## Character Selection UX

1. Browse character cards.
2. Select a character.
3. Open a large character preview.
4. Show animation clips below the preview.
5. Tap a clip to preview it.
6. Add character to the current scene.
7. Choose a clip and place it on the timeline.
8. Convert or edit the clip into user-owned animation data.

## Character Creation

Users can create characters from:
- blank canvas;
- modular body-part templates;
- imported artwork;
- vector/raster assets;
- custom rigs.

A custom character can be saved into the library and receive the same animation/rigging workflow as built-in characters.
