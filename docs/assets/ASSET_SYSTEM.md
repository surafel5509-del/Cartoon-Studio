# Asset System

Cartoon Studio uses a first-class, production-scale Asset System.

## Asset Categories

- Characters
- Character animations
- Props and objects
- Environments
- Backgrounds
- Foreground elements
- Nature and vegetation
- Ground and terrain
- Buildings and architecture
- Vehicles
- Creatures and animals
- Particles and VFX
- Textures and materials
- Brushes and palettes
- Audio and sound effects
- Music
- Voice assets
- Fonts
- Templates
- Poses
- Expressions
- Motion presets
- Camera presets
- Project templates

## Asset Lifecycle

Discover -> Preview -> Inspect -> Customize -> Add to Project -> Animate -> Save as Variant -> Reuse

Assets have stable IDs, metadata, tags, previews, dependency information, licensing/source information, versions and compatibility information.

## Local and Project Libraries

The system supports:
1. Built-in library
2. Downloaded/installed library
3. User library
4. Project-local library
5. Favorites and collections
6. Recently used assets

Assets must be reusable without duplicating large binary data unnecessarily.

## Search

Search should support names, tags, categories, animation types, style, color, orientation, age group, source, favorites and custom metadata.

## Asset Preview

Selecting an asset opens a preview inspector. For animated assets, the preview shows the character/object and an animation strip below it with available motions.

## Custom Assets

Users can create:
- new characters;
- new props;
- new environments;
- custom animation clips;
- custom brushes;
- custom particles;
- custom sounds;
- reusable templates.

Any user-created asset can be saved back into the library as a reusable asset.
