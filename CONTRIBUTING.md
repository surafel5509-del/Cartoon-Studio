# Contributing

Keep modules focused. Prefer immutable domain models where practical. Keep Android dependencies out of pure domain logic. Add tests with behavior changes. Document public contracts. Measure performance-sensitive changes.

## Commit Style

Use concise imperative commits such as feat: add timeline model, fix: correct interpolation, refactor: isolate renderer contract, test: add migration fixtures, docs: update architecture.

## Pull Requests

Explain what changed, why, testing performed, performance impact, and migration/compatibility impact.
